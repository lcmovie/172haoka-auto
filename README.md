# 172haoka-auto

适用于 172 号卡订单管理系统的 Tampermonkey（油猴）自动化助手。

## 功能

### 宽带商品自动上架

在“商品管理 → 宽带选品广场”中：

- 自动切换为每页 90 条并返回第 1 页
- 逐个点击“上架”并确认
- 识别后台排队提示，避免旧“上架”按钮造成重复提交
- 当前页全部提交后统一刷新，并轮询核验最终状态
- 自动遍历到最后一页
- 失败操作最多重试 3 次
- 支持随时安全停止

![宽带商品自动上架预览](./assets/product-auto-publish-preview.png)

### 代理商自动激活

在“代理商管理 → 代理商列表”中：

- 自动切换为每页 20 条并返回第 1 页
- 自动查找“激活”按钮并确认
- 自动遍历到最后一页
- 失败操作最多重试 3 次
- 支持随时安全停止

![代理商自动激活预览](./assets/agent-auto-activation-preview.png)

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开仓库中的 [haoka-auto-publish.user.js](./haoka-auto-publish.user.js)。
3. 点击 Raw，然后由 Tampermonkey 确认安装。
4. 登录目标系统并进入对应列表页面。
5. 使用页面右上角的控制面板手动启动任务。

## 使用提醒

- 脚本不会在页面打开后自动执行，必须手动点击开始并再次确认。
- 执行期间请保持目标页面开启，不要手动切换分页。
- 已上架商品和无需激活的代理会被自动跳过。
- 网站结构发生变化后，脚本选择器可能需要同步更新。
